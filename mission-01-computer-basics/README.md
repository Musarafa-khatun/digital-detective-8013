## 4. My understanding

### Task 1.1 — Trace one activity using IPOS
**Chosen Activity**: Searching for a lecture note online and saving it.

| Stage | What happens in your example? | Possible hardware / component |
|---|---|---|
| **Input** | The user types the search query into the web browser and presses the Enter key or clicks the search button. | Keyboard, mouse, or trackpad |
| **Processing** | The browser interprets the keystrokes, the operating system manages network communication, and the CPU processes the query and handles incoming network packets. | CPU (Central Processing Unit) and RAM (system memory) |
| **Output** | The browser renders the search result page with titles, links, and text descriptions on the monitor. | Monitor / display screen |
| **Storage** | When the user clicks "Save PDF", the file is written from temporary memory into non-volatile storage for future offline access. | SSD (Solid State Drive) or internal flash storage |

**Explanation**: 
The activity begins with an external signal provided by the user through an input device. The CPU, coordinating with RAM, processes these signals into network requests and handles the received data. The processed data is transformed into human-readable visual output on the display. Finally, the user chooses to make this data permanent by writing it to secondary storage (SSD).
